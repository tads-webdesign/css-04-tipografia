# CSS 04 - Tipografia

Notas de aula e tutorial completo sobre tipografia em CSS 3 para iniciantes.

## 📚 Conteúdo

Este repositório contém um tutorial detalhado sobre tipografia em CSS 3, abordando:

- **Propriedades de tipografia**: font-family, font-size, font-weight, line-height
- **Google Fonts**: Como integrar e usar fontes do Google
- **Fontes customizadas**: Usando @font-face para fontes próprias
- **Exemplos práticos**: Código HTML5 e CSS3 com demonstrações
- **Recursos avançados**: Links e materiais para aprofundamento

## 🚀 Como usar

### Ver o Tutorial
Acesse o arquivo [`tutorial.md`](tutorial.md) para ler o tutorial completo.

### Visualizar o Exemplo
1. Clone este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Explore os exemplos práticos de tipografia

### Estrutura do Projeto
```
css-04-tipografia/
├── README.md           # Este arquivo
├── tutorial.md         # Tutorial completo em Markdown
├── index.html          # Exemplo prático completo
└── styles.css          # Estilos CSS do exemplo
```

## 🎯 Objetivos de Aprendizagem

Ao concluir este tutorial, você será capaz de:

- ✅ Entender e aplicar as principais propriedades tipográficas do CSS 3
- ✅ Integrar Google Fonts em seus projetos
- ✅ Usar fontes customizadas com @font-face
- ✅ Criar hierarquias tipográficas eficazes
- ✅ Melhorar a legibilidade e acessibilidade dos textos
- ✅ Combinar fontes de forma harmoniosa
